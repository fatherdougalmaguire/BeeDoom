BeeDoom is an attempt to port Doom to the Microbee family of home computers.

Possibly a pointless endeavour but hopefully I can end up with something with a doom-like flavour.

I will be using VicDoom ( https://github.com/kweepa/vicdoom ) as a reference guide as the VIC-20 and Microbee are 8-bit platforms of similar vintage and capability.

But BeeDoom will not use any of VicDoom's code due to the uncertain licensing around it.
